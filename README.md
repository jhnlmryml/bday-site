# Web Birthday Gift

A mobile-first birthday surprise built with React and Vite. Tap the gift to reveal the birthday page and start the looping music.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Getting started

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |



The music starts only after the gift is tapped to comply with browser autoplay restrictions. The experience also respects the visitor's reduced-motion preference.
